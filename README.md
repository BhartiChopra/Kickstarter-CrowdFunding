# Kickstarter-CrowdFunding

# Introduction to the Project
- Kickstarter is a popular crowdfunding platform for creative projects.
- This project analyzes Kickstarter campaigns across multiple years using:
  - Excel Dashboard
  - Tableau Dashboard
  - Power BI Dashboard
- Focus: Category trends, project success, location performance, and funding patterns.


## Project Objectives
- Understand the factors contributing to successful crowdfunding campaigns.
- Compare project outcomes across categories, locations, and funding goals.
- Visualize data using different BI tools to extract actionable insights.
- Present findings in an interactive, business-friendly format.

## Challenges Faced During the Project
- Data cleaning: Inconsistent category and location fields.
- Time Handling: Converting data fields into usable hierarchies across tools.
- Performance Optimization in Power BI with slicers and interactions.
- Tool Differences:
   - Excel: Static and manual filtering
   - Tableau: Steep learning curve for filter syncing
   - PowerBI: Visual Customization limitations vs. performance


## Key Insights & Findings
- Failure Rate is High: Over 51% of projects failed.
- Top Performing Category: Product Design has both volume and success.
- Goal Impact: Projects with a goal under $10K are 3x more likely to succeed.
- Location Hotspots: Los Angeles, NY, and London lead in project count.
- Yearly Trend: Peak project creation between 2014-2016.
